# PHP Challenge: PHP Quiz App

Isang simpleng PHP script na gumagamit ng Constants, Variables, Arithmetic Operators, at Ternary Operator para kalkulahin ang porsyento ng score ng isang estudyante at matukoy ang kanyang status kung pasa o bagsak.

---

## 📌 Features / Requirements

- **Constant**: `APP_NAME` na may value na `"PHP Quiz App"`.
- **Variables**: Pag-declare ng mga data para sa pangalan ng estudyante (`$studentName`), nakuha kong score (`$score`), at pinakamataas na score (`$maxScore`).
- **Operators**: Pagkuha ng percentage score gamit ang pormulang `($score / $maxScore) * 100`.
- **Ternary Operator**: Pagtatakda ng status (`"PASSED"` o `"FAILED"`) base sa kondisyon na 70% pataas ang passing score.
- **Output**: Pag-print ng malinis at maayos na resulta ng quiz breakdown.

---

## 🖥️ Sample Output

Kapag in-execute sa browser:

```text
PHP Quiz App
Student Name: Manachan
Score: 85
Max score: 100
Percentage Score: 85
Status: PASSED
```
